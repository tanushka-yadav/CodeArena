# Contributing Guide

Thank you for improving CodeArena.

## Development Workflow

1. Create a feature branch.
2. Implement one focused feature.
3. Compile and run the application.
4. Add or update tests when the feature needs them.
5. Commit with a clear message.

## Code Style

- Keep classes focused on one responsibility.
- Follow MVC boundaries.
- Prefer meaningful names over comments.
- Use validation and exceptions for invalid states.
- Keep Swing UI code reusable and readable.

## Commit Format

```text
feat: add project foundation
fix: correct login validation
docs: update roadmap
test: add authentication tests
```
